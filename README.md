# CVAT QA/QC

Mã nguồn Chrome extension nằm trong [`chrome-extension/`](chrome-extension/).

- Cài extension dạng unpacked: chọn thư mục `chrome-extension` chứa `manifest.json`.
- Tài liệu sử dụng và kiểm thử: xem [`chrome-extension/README.md`](chrome-extension/README.md).
- Extension chạy trực tiếp từ mã nguồn, không cần Node.js hoặc bước build.
